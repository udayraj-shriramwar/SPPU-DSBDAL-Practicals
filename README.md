# SPPU DSBDAL Practicals

This repository contains Data Science and Big Data Analytics Lab (DSBDAL) practical programs and solutions based on the SPPU practical problem statements.

The practicals cover Hadoop MapReduce, HiveQL, Python data preprocessing, data visualization, Tableau, and web scraping.

## 📚 Practical List

### 1. MapReduce – Hadoop
Design a distributed application using MapReduce in Java to process a system log file and identify users who have logged for the maximum period.

**Technologies:** Java, Hadoop, MapReduce

---

### 2. HiveQL – Flight Information System
Develop a flight information system using HiveQL covering database and table operations, external tables, data loading, inserting values and fields, joins, indexing, and calculating average departure delay per day in 2008.

**Technologies:** HiveQL, Hadoop

---
